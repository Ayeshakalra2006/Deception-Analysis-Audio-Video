\# Deception Analysis Using Audio and Video



A multimodal AI-based project that analyzes audio and video signals to identify potential deception-related patterns.



\## Features



\- Audio-based analysis

\- Video-based behavioral analysis

\- Multimodal prediction using audio and video features

\- Interview-based question and answer analysis

\- Speech-to-text transcription

\- Fact extraction and contradiction detection

\- Session scoring and report generation



\## Technologies Used



\- Python

\- Streamlit

\- PyTorch

\- OpenCV

\- Librosa

\- Scikit-learn

\- Speech Recognition



\## Dataset



\*\*Real-Life Trial Deception Detection Dataset (RLTDD)\*\*



The dataset contains real-life courtroom trial videos used for deception detection research. Dataset files are not included in this repository.

\## Installation and Setup



1\. Clone this repository:



&#x20;  `git clone https://github.com/Ayeshakalra2006/Deception-Analysis-Audio-Video.git`



2\. Navigate to the project folder.



3\. Create and activate a virtual environment.



4\. Install dependencies:



&#x20;  `pip install -r requirements.txt`



5\. Run the application:



&#x20;  `streamlit run app.py`



\## Note



This project is developed for academic and research purposes. Its predictions indicate potential deception-related patterns and should not be treated as definitive proof that a person is lying.
